# LASS — Lab of Autonomous Structures and Systems

The official English-language website for Professor Bao Zhao's Lab of Autonomous Structures and Systems (LASS) at Beijing Institute of Technology, Zhuhai.

The site is intentionally dependency-free and built with semantic HTML, modern CSS, and a small amount of vanilla JavaScript. It is ready for GitHub Pages at [bao-zhao.github.io](https://bao-zhao.github.io/).

## Local preview

Run any static file server from the repository root, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Content source

Biography, research topics, appointments, education, publications, honors, and the portrait were adapted into English from Professor Zhao's [official BIT faculty profile](https://grd.bitzh.edu.cn/dsgl/dsfc/znkxyjs/de3b35feabf5490583cb7958a8a560e8.htm).
